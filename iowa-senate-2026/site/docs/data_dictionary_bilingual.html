Data dictionary / 数据字典

How to read a row / 如何读一行

English: Each dataset is one CSV with a fixed header, no blank cells, and unknown wherever a fact was not established. A row's source_urls cell contains exactly one SRC-####|https://… pair; the id resolves in 09_sources/sources.csv and the URL after the pipe must be identical to the URL registered there.

中文：每个数据集是一个表头固定的 CSV，不允许空单元格；凡未确认的事实一律写 unknown。每行的 source_urls 恰好包含一组 SRC-####|https://…，编号可在 09_sources/sources.csv 中解析，竖线后的网址必须与登记网址完全一致。

Derived values / 派生值

English: Percentages in election_results.csv, county_results.csv and polling.csv are either published figures (marked in notes) or recomputed from raw votes. Recomputation is stated in the row; published figures are never silently recalculated.

中文：election_results.csv、county_results.csv 与 polling.csv 中的百分比，要么是来源公布的数字（在 notes 中注明），要么由原始票数重算；重算必在行内说明，公布数字绝不悄悄改动。

Every CSV row carries SRC-####|https://...; unknown is a value, not a gap.

每个 CSV 行均带 SRC-####|https://...；unknown 是取值，不是缺失。
