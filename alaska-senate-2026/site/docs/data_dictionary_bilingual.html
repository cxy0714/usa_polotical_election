Data dictionary / 数据字典

How to read these tables

Every CSV is UTF-8, comma-separated, RFC 4180 quoting, LF line endings, with a single header row. All files share four conventions: unknown means "not published or not retrieved" and is never a blank; source_urls carries exactly one SRC-####|https://… pair resolving in 09_sources/sources.csv; dates are ISO YYYY-MM-DD or unknown; no cell is empty.

所有 CSV 均为 UTF-8、逗号分隔、RFC 4180 引号规则、LF 换行、单行表头。四个通用约定：unknown 表示 "未公布或未取得"，绝不留空；source_urls 只含一个可在 09_sources/sources.csv 解析的 SRC-####|https://…；日期为 ISO YYYY-MM-DD 或 unknown；任何单元格均不空白。

03_speeches/speech_archive.csv (12) and speech_video_index.csv (10)

speech_archive.csv: speech_id, event_id, date, speech_title, speech_url, transcript_url, duration, main_topics, major_quotes, rhetorical_devices, opponent_references, personal_story_elements, policy_claims, source, verification_status. major_quotes holds verbatim text with single-quote delimiters; multiple quotes separated by / .

speech_video_index.csv: video_id, video_url, date, duration, event_type, main_topics, relevant_timestamps, transcript_available, visual_observations, completeness. Rows are segment-level entries over three videos; relevant_timestamps is unknown because no timestamps were verified, and completeness is partial.

视频索引为三个视频上的片段级条目；relevant_timestamps 因未核实时间码而为 unknown， completeness 为 partial。

06_campaign_finance/campaign_finance.csv (8 rows)

07_electoral_context/*.csv (12 + 0 + 8 rows)

  • election_results.csv: race_id (AK-SEN-2026-GEN, AK-SEN-2026-PRIMARY), race_name,

    • election_date, candidate, party, votes, percentage, winner (yes/no), notes. Includes a Total votes cast row for each race; its winner is no by convention because a total is not a candidacy.

  • county_results.csv: required header, zero rows — Alaska reports by state house district, not

    • county (see results_notes.md).

  • polling.csv: poll_id, pollster, sponsor, field_start, field_end, population

    • (LV/RV/unknown), sample_size, margin_of_error, peltola_pct, sullivan_pct, other_pct, undecided_pct, leader, margin, notes. Percentages are first-round unless notes says the pollster allocated eliminated candidates.
