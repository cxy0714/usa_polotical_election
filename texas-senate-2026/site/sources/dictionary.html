Bilingual data dictionary / 双语数据字典

Why this file exists. The CSV datasets are the machine-readable backbone of the archive: their field names and controlled-vocabulary values stay in English so that the data remains schema-stable, joinable and validatable. Translating values inside cells (for example turning verified into 已核实) would break every validator, join and script. This document is therefore the Chinese reading layer: every field name, every controlled value and every measurement caveat is glossed here, so a Chinese-speaking analyst can read any CSV accurately without the data being mutated.

本文件的作用。 CSV 数据集是本档案的机器可读骨架：字段名与受控词表取值一律保持英文，以保证结构稳定、可连接、可校验。若把单元格里的取值翻译成中文（例如把 verified 写成"已核实"），所有校验脚本、表连接与自动化都会失效。因此本文件充当"中文阅读层"：逐字段、逐取值给出中文释义，并说明全部度量口径陷阱，使中文读者能准确读懂任何一张 CSV，而数据本身不被改写。

1. Reading rules / 阅读规则

  1. 字段名与取值保持英文，中文释义见下文表格；不要在原 CSV 内改写成中文。 Field names and values stay English; look up the Chinese gloss here. Never translate inside the CSV.
  2. unknown 表示"未能查明"，不是 0、不是"无"、不是"否"。凡见 unknown，即表示该事实 在本档案的检索范围内无法确立，须保持不确定。 unknown means "not established" — not zero, not none, not no.
  3. 同一行内的数字不得跨行相加，除非该表明确声明同一口径（详见第 6 节）。 Never sum numbers across rows of different measurement constructs (§6).
  4. 凡字段内出现 SRC-####|URL 形式，表示该行引用了 09_sources/sources.csv 中的来源条目； | 之前是来源编号，之后是该来源的 URL 副本，便于离线阅读。 SRC-####|URL pairs point into 09_sources/sources.csv.
  5. 核实状态字段在各表中一致使用四个取值，见 §4.1。 The verification field uses the same four values in every table (§4.1).

6. Measurement traps / 度量口径陷阱（务必遵守）

  1. FEC 独立支出（Schedule E）≠ AdImpact 广告投放额。 两者相差约一个数量级； 例：某团体 FEC 记录 2,496 万美元，而 AdImpact 口径可达 1.821 亿美元。绝不可相加或互相替代。
  2. 塔拉里科存在四种"总额"：阵营宣称累计 1.343 亿、FEC 捐款 1.403 亿、 FEC 总收入 1.463 亿、含联合筹款委员会约 1.55 亿。各自口径不同。
  3. 帕克斯顿第三季度"1,800 万美元" 含两个联合筹款委员会，主委员会为 1,024.9 万美元。
  4. 选举夜 66% 计票的 59.4% 不是结果，只是部分计票；最终为 55.06%。
  5. 帕克斯顿巡回宣传"30+ 站" 为阵营宣称；某地方媒体称"12 站之一"，两者并存。
  6. "三场已排定辩论" 系某媒体误报，从未发生，不得列入事件表。
