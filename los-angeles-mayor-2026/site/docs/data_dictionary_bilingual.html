2. The source_urls cell / source_urls 单元格

Format: SRC-####|https://… — exactly one pair per cell, no whitespace. The SRC-#### must resolve in 09_sources/sources.csv, and the URL must be identical to that row's url (trailing slashes ignored). Corroboration for a row goes in notes, reliability_notes or verification_status, never in a second pair. Every source row in turn must appear in _staging/fetch_log.csv with http_status = 200; blocked and paywalled pages are logged there and reported in research_gaps.md, never cited.

格式：SRC-####|https://…——每格恰好一对，不含空白。SRC-#### 必须在 09_sources/sources.csv 中可解析，且 URL 与该行 url 完全一致（忽略末尾斜杠）。行内交叉印证写入 notes、reliability_notes 或 verification_status，绝不加第二对。每个来源行又必须出现在 _staging/fetch_log.csv 且 http_status = 200；被封锁与付费墙页面只记录于彼处并在 research_gaps.md 中报告，绝不引用。

3. unknown / unknown 的语义

unknown = "no retrieved source establishes this". It is a value, never a zero, never "no". Numeric columns may contain it (e.g. debts_owed, other_pct, individual_contributions). Text columns may contain it (e.g. venue, author, clothing_notes). No row is deleted because a field is unknown.

unknown = "没有已获取来源可确立此项"。它是取值，绝不是零、绝不是"否"。数字列可含之（如 debts_owed、other_pct、individual_contributions），文本列亦可含之（如 venue、author、 clothing_notes）。任何行都不因某字段未知而删除。

6. Dataset-specific notes / 各数据集说明

02_campaign_events. stated_purpose and observable_function are descriptive; every evaluative sentence is in analyst_interpretation and begins with INTERPRETATION:. visual_notes is unknown wherever the build could not view imagery. speech_summary paraphrases only what a retrieved text reports.

02_campaign_events。 stated_purpose 与 observable_function 为描述性；所有评价性句子都在 analyst_interpretation 中并以 INTERPRETATION: 开头。凡本次构建无法查看影像，visual_notes 即为 unknown。speech_summary 仅转述已获取文本所述内容。

03_speeches. major_quotes uses "…" around verbatim text and records the source's framing when the quote reached the archive via a columnist. duration is unknown for every row: no player metadata was readable.

03_speeches。 major_quotes 用引号标出逐字文本，并在引语经由专栏作者转述时记录该框架。 所有行的 duration 均为 unknown：未能读取任何播放器元数据。

04_visual_archive. framing, camera_angle, image_quality, face_visibility, body_visibility and clothing_notes are unknown unless a published caption or report states the detail — this build had no image input. copyright_status = all_rights_reserved_link_only marks press photography that is described and linked but not redistributed.

04_visual_archive。 除已发表图说或报道明确提及外，framing、camera_angle、image_quality、 face_visibility、body_visibility、clothing_notes 均为 unknown——本次构建无图像输入。 copyright_status = all_rights_reserved_link_only 标记仅描述并链接、不再分发的新闻摄影。

05_campaign_media. advertisements.length_seconds is unknown except Raman's 30-second Emmy spot (as reported). main_visual_elements for the Bass ICE spot and the LAPPL ad is the L.A. Times newsletter's description, not the archive's viewing. social_media rows are campaign YouTube posts whose titles were verified through oEmbed; engagement counts were not retrievable.

05_campaign_media。 除 Raman 的 30 秒艾美奖广告（据报）外，advertisements.length_seconds 均为 unknown。Bass 移民执法广告与 LAPPL 广告的 main_visual_elements 来自洛杉矶时报通讯的描述， 而非档案的观看。social_media 各行为竞选 YouTube 发布，标题经 oEmbed 核实；互动数据不可获取。

06_campaign_finance. period = reported-through date. report_type distinguishes primary_cycle_reported_through, runoff_cycle_reported_through, independent_expenditure_committee_receipt and independent_expenditure_against_candidate. The last two are not candidate money; see _research_conventions.md §5.

06_campaign_finance。 period = 申报截止日。report_type 区分初选周期、决选周期、独立支出 委员会收款、以及针对某候选人的独立支出。后两类不是候选人资金；见 _research_conventions.md §5。

07_electoral_context. party is Nonpartisan throughout by law. county_results.csv is header-only by design (results_notes.md §6). polling.population is LV (likely voters) for all eight rows; margin_of_error is unknown where the pollster published none.

07_electoral_context。 party 依法一律为 Nonpartisan。county_results.csv 按设计只有表头 （results_notes.md §6）。polling.population 八行全为 LV（可能投票者）；margin_of_error 在 民调机构未公布时为 unknown。

8. Joining the tables / 表间连接

candidate_id joins everything (BASS, RAMAN, plus JOINT, PRATT, MILLER, HUANG as documented in _research_conventions.md §6). event_id joins campaign_events to speech_archive, media_coverage and image_archive. source_urls joins any table to sources.csv. There is no district key anywhere, because no district-level data was retrieved.

candidate_id 连接所有表（BASS、RAMAN，另加 JOINT、PRATT、MILLER、HUANG，见 _research_conventions.md §6）。event_id 连接 campaign_events 与 speech_archive、 media_coverage、image_archive。source_urls 连接任意表与 sources.csv。任何表中都没有 district 键，因为未获取任何分区级数据。

Every CSV row carries SRC-####|https://...; unknown is a value, not a gap.

每个 CSV 行均带 SRC-####|https://...；unknown 是取值，不是缺失。
