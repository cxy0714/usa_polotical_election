Data dictionary / 数据字典

1. Shared conventions / 通用约定

Field patternMeaning / 含义
*_idStable identifier; never reused. SRC-#### for sources, EV-### events, POS-### positions.
source_urlsExactly one `SRC-####https://… pair; the id must exist in sources.csv` and the URL must match it.
verification_statusverified, partially verified, unverified, conflicting sources.
datesISO YYYY-MM-DD; unknown when no record fixes the date.
unknownA value, not a placeholder.

source_urls 单元格只允许一个 SRC-####|https://… 组合，且必须与 sources.csv 对应行一致。

2. 09_sources/sources.csv

ColumnDefinition
source_idSRC-####, assigned in retrieval order.
urlThe exact URL retrieved and mirrored.
titlePage title as served, or a descriptive title where the page is a PDF/API response.
publisherDomain owner, mapped from the host.
publication_dateDate the page states it was published (unknown if absent).
event_dateDate of the event the source documents (may equal publication_date).
access_dateAlways 2026-11-18 for this case.
source_tierT1 official, T2 journalism, T3 synthesis.
source_typeofficial_government, official_campaign, news_article, poll, press_release, photo, encyclopedia, analysis, op_ed, fact_check, other.
relevant_quote_or_infoThe specific fact or quote this source supplies.
reliability_notesProvenance caveats: paywall, syndication, JS shell, 403 mirror substitution.
used_byWhich dataset or document relies on it.

7. 06_campaign_finance/campaign_finance.csv

period is ISO (2026-09-30) or YYYY-Qn; report_type names the filing; receipts, disbursements, cash_on_hand are integers as printed; individual_contributions, pac_contributions, debts_owed are unknown when the source table omits them.

8. 03_speeches/speech_archive.csv and speech_video_index.csv

ColumnDefinition
speech_idSP-###.
event_idThe EV-### this speech belongs to, or unknown where the speech was an interview or a statement with no archived event.
speech_url / transcript_urlDirect audio/video or transcript URL; unknown where only reporting exists.
durationSeconds, as stated in the file metadata; unknown where no recording exists.
major_quotesVerbatim quotes only. Where the source paraphrases, this cell says so instead of inventing a quote.
rhetorical_devicesNamed devices observed in the quoted passage; unknown where nothing is quoted.
sourceWhat kind of document the quotes come from (report, release, floor record).

speech_video_index.csv uses video_id (VID-###), video_url, completeness (full, partial, clip, unknown) and visual_observations, which is unknown whenever the archiver did not inspect the file.

9. 04_visual_archive/image_archive.csv

ColumnDefinition
image_idIMG-###.
event_idDated event the image documents, or unknown.
source_urlThe Wikimedia Commons file page (not the binary URL); the binary is in original_image_url.
photographerCredit string from the Commons API, required for CC BY / CC BY-SA reuse.
copyright_statuspublic_domain, licensed, all_rights_reserved_link_only, unknown.
licenseThe licence string exactly as the API returns it.
local_filenamePath under 04_visual_archive/, or unknown for catalogue-only rows.
image_resolutionWxH in pixels, from the API or measured from the downloaded file.
framingRead from the Commons title/description only.
clothing_notes, camera_angle, face_visibility, body_visibilityunknown throughout: this build has no image-reading step, and no retrieved caption describes them.

10. 05_campaign_media/ — three tables

advertisements.csv: ad_id (AD-###), sponsor_type (controlled: candidate_campaign, authorized_committee, outside_pac, party_committee, unknown), main_claims (transcript excerpt or a statement that no script was retrieved), fact_check, video_url (often unknown because ad libraries were unreachable).

social_media.csv: post_id (SOC-###), platform, account_handle, post_date, post_type, url. Where a post could not be retrieved directly, notes says how it was documented — quoted in reporting, quoted in a Commons description, or a post later deleted.

media_coverage.csv: coverage_id (MC-###), coverage_type (controlled), and a plain url column (not source_urls) holding the article URL; key_framing is the analyst's reading of the article's angle, while notable_quotes holds only text the article actually prints.

11. 07_electoral_context/county_results.csv

county_id, county, brown_votes, husted_votes, other_votes, brown_pct, husted_pct, total_votes, source_urls, verification_status. This file holds a header and zero rows in this build: no county vote table was retrievable. See results_notes.md, "The county picture".

12. 01_candidates/<candidate>/career_timeline.csv

entry_id, candidate_id, start_date / end_date (ISO or unknown), role_or_event, organization, location, description, source_urls, verification_status. Dates for Husted's Senate service start at 2025-01-21 (the oath), not at the appointment.

13. Vocabularies enforced by the validator / 校验器强制词表

event_status, campaign_phase, event_category, issue, sponsor_type, coverage_type, copyright_status, verification_status, source_tier, source_type, completeness, winner. 04_visual_archive/image_archive.csv is the one place where event_category is free text, because images can document things that are not campaign events.

image_archive.csv 的 event_category 是唯一允许自由文本的枚举列（图片可记录非竞选活动的内容）。
