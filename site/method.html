方法与限制 Method and limits

这八份档案只记录能被公开来源支持的陈述。每张表、每一行都可以追溯到一条 SRC-#### 编号；来源没有说的，字段写 unknown，不写猜测。

These eight archives record only what a public source supports. Every row carries a SRC-#### citation to a URL in that case's 09_sources/sources.csv. Where the source is silent the field reads unknown — never a guess.

1. 来源分层 / Source tiers

Tier是什么 / What例子 / Examples
T1官方记录：选举机构、国会、法院、财务申报 FEC filings, state canvasses, Senate roll calls, FEC candidate pages
T2有编辑责任的新闻与专业媒体 AP, Reuters, statehouse bureaus, local television, trade press
T3参考性与一手影像来源 Wikimedia Commons, Wikipedia (used only for pointer facts), campaign uploads

Tier is recorded per source; it is not a truth score. A T3 upload can be the only record of what a candidate said, while a T2 article can repeat a campaign claim without checking it.

2. 三类视觉证据 / Three classes of visual evidence

Class是什么 / What it is如何标注 / How it is labelled
A文本描述的舞台：文章或图注描述场景、背景、人群、着装 cited to the outlet; unknown where silent
B对授权图像的直接观察 “observed in [IMG-id]” — one image, one date, not a general claim
C品牌与图像符号：巡游名称、口号、广告创意 cited; interpretation prefixed INTERPRETATION:

A sentence like “candidate X dresses minimally” is supportable only as a Class A statement from a retrieved source or a Class B observation tied to a named image. Otherwise the clothing field stays unknown — that is why most rows in this archive say exactly that.

3. 图像与视频层 / The image and video layers

新闻照片只记录文章 URL、图注与署名：照片本身多为版权保留，档案不复制文件，字段标为 all_rights_reserved_link_only。只有公有领域或知识共享的肖像才真正下载保存。

Credited news photographs are stored as link and credit only (all_rights_reserved_link_only); the file is not copied. Only public-domain or Creative-Commons portraits are downloaded.

视频层使用 YuNet 做人脸检测、SFace 与已授权肖像比对，判定门槛为余弦 ≥ 0.363 且领先第二名 ≥ 0.05， 否则记 unknown。它回答的是“这一帧里更可能是谁”，不是“他穿了什么”。

The video layer runs YuNet face detection and SFace comparison against licensed portraits, with a cosine threshold of 0.363 and a 0.05 margin over the runner-up; anything below stays unknown. It answers “who is more likely in this frame”, not “what are they wearing”.

已知偏差 / Known bias. 识别器只能在两位提名人之间二选一，主持人、代理人或观众会被归给较接近的一位； 参考肖像不足时覆盖率会明显下降（艾奥瓦的 Turek 只有一张合影作参考，一帧都未识别出）。 The recogniser is a two-class instrument: moderators, surrogates and crowd members are assigned to whichever nominee is closer. Thin portrait supply lowers coverage sharply — Iowa's Turek has one group photograph as reference and is never identified.

4. 复现 / Reproduce

仓库自带校验与重建脚本，克隆后可直接跑：

python _tools/validate_case.py ohio-senate-2026   # header, vocab, SRC resolution
python _tools/build_case_site.py ohio-senate-2026 # rebuild one case site
python _tools/build_portal.py                     # rebuild the eight-case portal
python _tools/live_check.py <pages-url>           # crawl the deployed demo

Every published page is generated from the CSVs; nothing on the site is hand-edited. The audit trail of fetched pages lives under each case's _staging/mirrors/ and is excluded from git (third-party publisher text), while _staging/fetch_log.csv records every URL, status code and saved file.

5. 这不是什么 / What this is not

  • 不是民调或预测模型；结果栏只记录已公布的计票。
  • 不是“候选人形象”的论证；着装与舞台大多只能记 unknown。
  • 不是完整新闻剪报库；每天新增的来源会改变计数，但不会改写已引用的行。

Not a poll or a forecast; not an argument about candidate image; not a complete press clipping library. Counts move as sources are added, but cited rows are not silently rewritten.
