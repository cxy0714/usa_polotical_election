Rule applied / 适用规则

Where a report says an event happened but gives no crowd, the row's observable_function describes what was observable (a press conference, a roundtable with named participants) and analyst_notes says the crowd is unknown. No number is estimated.

中文：若报道确认活动发生但未给人数，则该行只记录可观察到的形式（记者会、有名有姓的圆桌参与者），并在 analyst_notes 注明人数不明；本档案不做任何人数估算。

Every CSV row carries SRC-####|https://...; unknown is a value, not a gap.

每个 CSV 行均带 SRC-####|https://...；unknown 是取值，不是缺失。
